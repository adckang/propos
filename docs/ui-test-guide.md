### TC-UI-002 · 정상 흐름 (전체 성공)

| 7 | 마지막 실행 시각 | 헤더 우측 `마지막 실행 HH:MM` 표시 |

### TC-UI-003 · 오류 흐름 (PIN 등록 실패)

| 순서 | 액션 | 기대 결과 |
|------|------|----------|
| 1 | 오류 시뮬레이션 토글 클릭 | 토글 빨간색으로 변경 |
| 2 | `▶ 지금 실행` 클릭 | 실행 시작 |
| 3 | P-007 카드 확인 | `[실패]` 빨간 상태 |

| 8 | 알림 피드 확인 | error 알림 1개 (빨간) + info 알림 3개 |

### TC-UI-005 · 재실행 시 상태 초기화

> 섹션 0 대응 — 매 실행마다 새 결과로 덮어써야 함

| 순서 | 액션 | 기대 결과 |
|------|------|----------|
| 1 | 정상 실행 완료 후 결과 확인 | 카드 4개 완료 상태 |
| 2 | `▶ 지금 실행` 다시 클릭 | 이전 결과 카드 초기화 |
| 3 | 재실행 중 확인 | 카드 처음부터 다시 순차 등장 |
| 4 | 알림 피드 확인 | 이전 알림 초기화, 새 알림만 표시 |

**Pass 기준:** 4개 항목 모두 충족

### TC-UI-006 · 처리 순서 검증

> 섹션 1→2→3 순서 대응 — PIN 발급 후 메시지, 그 후 스마트홈 순서여야 함

| 순서 | 액션 | 기대 결과 |
|------|------|----------|
| 1 | 실행 후 첫 번째 카드 처리 중 관찰 | `…PIN` 칩 먼저 등장 |
| 2 | PIN 완료 후 | `✓PIN` → `…메시지` 순으로 전환 |
| 3 | 메시지 완료 후 | `✓메시지` → `…스마트홈` 순으로 전환 |
| 4 | 전체 완료 | `✓PIN ✓메시지 ✓스마트홈` 순서 확인 |

**Pass 기준:** 4개 항목 모두 충족

### ⚠️ UI 미구현 항목 (시퀀스 대비 Gap)

> 시퀀스 다이어그램에 명시되어 있으나 현재 UI에서 확인 불가한 항목.
> 향후 구현 시 TC 추가 예정.

| Gap | 시퀀스 섹션 | 설명 | 우선순위 |
|-----|-----------|------|---------|
| 알림 ACK 버튼 | 섹션 4 | `Admin -> AlertFeed : 알림 확인 (ack 클릭)` → 뱃지 해제 기능 없음 | 높음 |
| PIN 유효기간 표시 | 섹션 1 | PIN 발급 시 유효기간(체크인-1h ~ 체크아웃) 카드에 미표시 | 중간 |
| 웰컴 메시지 내용 | 섹션 2 | 게스트명·PIN·WiFi 포함 여부를 UI에서 확인 불가 | 중간 |
| 스마트홈 씬 상세 | 섹션 3 | 조명 100%, 에어컨 26°C 설정값 UI 미표시 | 낮음 |
